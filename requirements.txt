# ----------------------------------------------------------
# 关于 MySQL 驱动（PyMySQL）
#
# 它被单独拆到了 requirements-mysql.txt，不在核心依赖里。原因有两个：
#
#   1) 按需加载：只有把数据库从 SQLite 切成 MySQL 时才用得到，
#      SQLite 模式下装了也是白占地方。
#
#   2) 云端发布限制（这个更关键）：
#      发布沙箱只提供一个 HTTP 端口，不提供外部数据库服务。
#      只要核心依赖清单里出现了 MySQL 驱动，整个项目就会被判定为
#      "需要外部服务"而拒绝发布 —— 哪怕代码实际跑的是 SQLite。
#      所以拆开之后，云端发布才能通过。
#
# 需要 MySQL 时执行： pip install -r requirements-mysql.txt
